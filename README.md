# Trang chủ với Bootstrap

Mở index.html trong trình duyệt có Internet. Bootstrap 5.3.3 và Font Awesome 6.5.2 được tải từ CDN theo đề bài.

- Navbar có Font Awesome và menu responsive.
- Carousel hai ảnh SVG cục bộ, nút trước/sau và indicators, tự chuyển mỗi 6 giây.
- Display utilities: d-block w-100, d-none d-md-block.
- Section căn giữa bằng d-flex justify-content-center align-items-center.
- Spacing utilities: py-5, px-3, mt-4, mb-3, g-4.
- Form có label, form-control, btn-primary, kiểm tra trường bắt buộc và email.
- Form gửi hợp lệ chỉ hiển thị thông báo minh họa, không gửi hoặc lưu dữ liệu.

Ảnh được vẽ cho bài và lưu trong images/. Ảnh nộp bài: desktop.png, mobile.png.
